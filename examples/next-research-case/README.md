# Какой пробел закрыть первым

Авторские вымышленные документы, не официальный бриф и не реальные данные продукта.
Текущая граница решения — выбрать способ ПОДГОТОВКИ сценария заявки.

- [Сравнение исследовательских вопросов](research-selection-R1.md).
- [Записка](decision-brief.md).
- `review.json` — заполненная версия, сохранённая CLI в `project.json`.

Q1 — разрешена ли интеграция: критический вопрос осуществимости. Q2 — достаточен
ли шаблон: следующий вопрос. Q3 — цвета конкурентов: не различает текущие варианты.
Доступное чтение условия сравнивается с интервью, которые не заменяют это условие.
Длительность и ресурсы неизвестны, а не равны нулю.

```sh
python scripts/project_tool.py audit examples/next-research-case/project.json --ready --quality
python scripts/verify_research_demo.py
```

Демонстрация в отдельной временной копии действительно читает POLICY и FORM,
сохраняет E2/E3 с точными фрагментами и воспроизводит подготовленный пересмотр:
Q1 → Q2 → stop для текущего решения. Сохраняются три версии, старые приоритеты
помечаются stale. Приоритетные вопросы не спрашиваются заново. Вывод о достаточности
подготовки не означает подтверждения спроса, UX, запуска или эффекта.
