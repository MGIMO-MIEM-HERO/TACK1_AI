# Начать работу с агентом

Откройте в Codex или Cursor именно эту папку — рядом должны находиться
`AGENTS.md`, `scripts/` и `workflows/`. Попросите ассистента:

> Прочитай AGENTS.md. Выполни python scripts/start.py
> examples/campus-strategy/project.json --json. Объясни рекомендацию,
> ограничения и следующий шаг. Не фиксируй мой выбор. Используй реальные пути
> инструкций из workflow_files, не придумывай имена файлов.

Это учебный кейс. Для своей задачи создайте отдельный проект:

```text
python scripts/project_tool.py new projects/my-case --title "Мой продукт" --objective "Какое решение нужно принять"
python scripts/start.py projects/my-case/project.json
```

Передайте агенту цель, срок, ограничения и материалы. Он подготовит рамку,
исследование, альтернативы и предложение проверки. Если данных недостаточно,
он должен назвать неизвестное. Выбор и обязательства согласуются с вами.

Для продолжения в новом чате укажите точный путь к тому же `project.json`
и попросите выполнить `start.py`. Команда не меняет файлы и не вызывает модель;
смысловую работу выполняет ассистент текущей среды. Предупреждения не скрываются,
успешный структурный аудит не подтверждает истинность выводов.

Расходы: `python scripts/ledger.py report <project.json>`. Нулевой известный
подытог при неизвестных расходах не означает бесплатный запуск.

Подробнее: [быстрый запуск](docs/quickstart.md),
[изменения версии](docs/agent-v3.md).
