# Авторский пример проверки решения на прочность

Это вымышленное условие о подготовке сценария заявки, не официальный кейс
МегаФона и не результаты исследования пользователей. Все сценарии гипотетические.

Откройте [записку](decision-brief.md): рекомендация O1 и три сценария с исходами
сменить на O2 / сохранить O1 / запросить данные. На каждый сценарий сравниваются
все четыре варианта; решение человека отсутствует. Полностью заполненная версия
разбора находится в `review.json` и сохранена в `project.json` с реальной датой
записи через `stress_test.py record`. Журнал не содержит выдуманной цены/токенов.

```sh
python scripts/validate_project.py examples/decision-stress-case/project.json
python scripts/project_tool.py audit examples/decision-stress-case/project.json --ready --quality
python scripts/verify_stress_demo.py
```

Последняя команда безопасно воспроизводит пересмотр в отдельной временной
копии: новое ограничение → устаревший разбор → запрет финального экспорта →
подготовленная новая рекомендация/стратегии → версия R2 с сохранением R1.
Она проверяет механику работы со сценарием, а не успешность реальной стратегии.
Осуществимость за три дня, спрос, затраты и эффект пока неизвестны.
