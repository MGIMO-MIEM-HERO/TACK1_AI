# Статичные карты для README

В начале README размещена [карта анализа учебного снимка](analysis-map.md):
источники, устаревшие основания, неизвестное, сравнение альтернатив и два
разных выбора. Её исходник — `scripts/build_agent_analysis_map.py`.

[`agent-work-graph.svg`](agent-work-graph.svg) — общая схема процесса и записанных
оснований агента. Она не использует кейс, пользовательские материалы или
результаты измерений. Стрелки обозначают маршрут работы, не причинность;
проверки могут повторяться и возвращать к уточнению. Это не журнал скрытых
рассуждений и не доказательство истинности выводов.

Рекомендация показана светлым фиолетовым блоком, решение человека — отдельным
тёмным. Неизвестное остаётся отдельной категорией, а не фактом или доказанной
невозможностью. Пунктир возвращает к материалам при изменении оснований.

## Соответствие существующим структурам

| Блок | Где реализовано |
|---|---|
| Задача и ограничения | `objective`, `constraints`, `unresolved_questions` в [схеме проекта](../../schemas/project.schema.json) |
| Материалы → основания | `sources`, `evidence`, `source_ids`, `support`, `related_evidence_ids`; [построение карты](../../scripts/visualize.py) |
| Альтернативы | `options`, `evidence_ids`, `kind`; [инструкции агента](../../AGENTS.md) |
| Ресурсы и осуществимость | `feasibility_reviews`; [порядок проверки](../feasibility-check.md) |
| Неблагоприятные сценарии | `decision_stress_tests`; [разбор сценариев](../decision-stress-test.md) |
| Существенные обещания | `marketing_claims`, `marketing_claims_audits`; [аудит обещаний](../marketing-claims-audit.md) |
| Рекомендация ≠ решение | `recommended_option_id`, `recommendation_rationale`, `chosen_option_id`, ответы на версии; [паспорт решения](../../workflows/decision-passport.md) |
| Новые данные и пересмотр | [существенные изменения](../../workflows/material-change-review.md), [продолжение](../../workflows/decision-follow-up.md) |

## Редактирование и проверка

Редактируемый источник: [генератор на Python stdlib](../../scripts/build_agent_work_graph.py).
Он создаёт только эту схему, не читает проекты и не меняет встроенную карту.

```sh
python scripts/build_agent_work_graph.py
python scripts/build_agent_work_graph.py --check
```

SVG содержит локальные фигуры и текст с системными шрифтами, без скриптов,
внешних ресурсов, ссылок или зависимостей. GitHub отображает его через обычную
Markdown-картинку; запуск кода нужен только для редактирования.

При изменении схемы проверьте отрисованный README в ширине 900 и 390 px,
включая подписи, стрелки, границы карточек и отсутствие горизонтальной прокрутки.
Текущая схема проверена в Edge как SVG внутри Markdown: все подписи внутри
карточек, при 390 px изображение занимает примерно 343 px, основной текст —
около 12 px. Это локальная проверка отображения, не полный аудит доступности.
