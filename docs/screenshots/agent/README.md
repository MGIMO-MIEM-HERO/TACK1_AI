владельца в снимках нет. Для обновлённой пары снимков сценариев используется

## Что означает рекомендация

OR — исследовать одну предотвратимую причину семейного перебоя до выделения
бюджета на продуктовый пилот. Частота проблемы, эффект, доступ к данным и
полный ресурс команд остаются неизвестными. Рекомендация исследования не
равна одобрению разработки; выбор владельца и согласие не записаны.

Источник F_RIGHTS подтверждает содержание условия, не причинный эффект.
Сценарные оценки не применяются автоматически к реальному выбору. История
показывает сохранённые записи, не восстанавливает прежнее состояние карты.
Это визуализация оснований и объяснений, не скрытых рассуждений модели.

В Git публикуются только выбранные снимки, инструкция, скрипт и контрольные
хеши. Исходные PDF, JSON, HTML, полные извлечения и сам чат не копируются в
публикационные файлы. Полосы прокрутки в снимках оставлены; текст интерфейса
не подменён. Для сценарной таблицы увеличена высота окна браузера, чтобы все
шесть строк поместились в настоящую панель.

## Воспроизведение при наличии локальных материалов прогона

Из корня рабочей копии, где сохранилась локальная папка кейса:

```sh
python scripts/capture_readme_screenshots.py --graph projects/pdf-brief-mobile-2026-11-22-abc8fb4/work-graph.html --project projects/pdf-brief-mobile-2026-11-22-abc8fb4/project.json --agent-commit abc8fb468b37d5b3e069de03ce9be12fb118db65
```

Повторите ту же команду с `--full-only` для общего графа, с `--overview-only` — только для пары снимков пути рекомендации. Для съёмки нужны
Edge и `websocket-client`, как для существующих браузерных проверок.
Локальный кейс не входит в Git; без него доступны готовые PNG, а скрипт
потребует реальные пути. Он не подставит прежний демонстрационный кейс.

Скрипт проверяет совпадение SHA-256 project.json с версией, встроенной в HTML.
Съёмка выполняется в изолированном профиле Edge; показанный текст и стили не
переписываются. DOM-ID добавляется лишь для выбора области цитаты.
`capture.json` и `full-capture.json` фиксируют ID кейса, версии, SHA-256 JSON/HTML,
выбранное основание и размеры. Во время съёмки данные графа, JSON и HTML
сохраняются неизменными. Часы в кадрах относятся к исходному экспорту карты,
а не к моменту принятия решения или новой съёмке.

Проверены все 11 PNG, ссылки и отрисовка README при 900/390 px: шесть картинок
загружаются, пять отдельных представлений переключаются на мобильные версии,
горизонтальной прокрутки нет. Это проверка отображения, не полный аудит
доступности и не независимая экспертиза стратегии.

## Обновление снимка сценариев

Пара `04-scenarios-provisional.png` / `04-scenarios-provisional-mobile.png`
снята из опубликованной обезличенной карты
[`demo/megafon-family-strategy/work-graph.html`](../../../demo/megafon-family-strategy/work-graph.html)
в версии разбора `S4-4818ce8`, сценарий `SC2` — «Польза есть, дополнительных оплат нет».
Это актуальное представление предварительных оценок, соответствующее присланному
примеру; сохранены все шесть строк, включая O0, OR и OS.

Источник, SHA-256 HTML, встроенная версия состояния, размеры и контрольные суммы
новых снимков записаны отдельно в `scenarios-provisional-capture.json`.
Метаданные `capture.json` и старые файлы `04-scenarios*.png` без `provisional`
сохранены как история предыдущей съёмки S1-PDF / SC1; README на них больше не ссылается.
Общие сведения о первоначальной съёмке выше относятся к остальным изображениям.

Новые снимки получены из настоящего интерфейса Chromium через Playwright.
Менялись только размер окна и выбранный сценарий; текст, стили и данные карты
не переписывались. Высота окна увеличена так, чтобы таблица поместилась целиком.
Предварительные оценки не означают выделенного ресурса, запуска или выбора владельца.
