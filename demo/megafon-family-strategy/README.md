# Демонстрационный проект: связь для близких

Материалы работы стратегического агента «Контур решения» в чате **«Прогон 3»** по учебному брифу конкурса МГИМО / МегаФон. Оператор и числа вымышлены. Дата комплектации: 22 ноября 2026.

**[Презентационный PDF](demo-project.pdf)** · [Полная стратегия](strategy.md) · [Интерактивная карта](work-graph.html)

## Что решает руководитель

К концу Q1 определить объём и условия первого пилота, в Q2 вместе с финансовой командой решить, расширять ли его. Текущая рекомендация **OR**: сначала проверить причину проблемы, измеримость и ресурсы. Кандидат последующего продукта **O1** — своевременный сигнал о низком остатке и ссылка на существующее распределение семейного интернета.

## Статус результата

Это демонстрационный проект и условный план, а не выполненный пилот или утверждённая стратегия компании. Выбора и разрешения владельца нет. Люди, QA, смета, исходная частота проблемы и размер выборки не подтверждены. Финальный экспорт агента остаётся заблокирован отсутствием отдельно оформленного `validation_design`; читаемая редакционная упаковка этого блокера не снимает.

Пакет собран из исходного прогона и его продолжения на коммите `4818ce8ab56288ee549a4e091461fadd5c44a2a4`. Это не новый независимый сквозной прогон. Сырые журналы чата, личные пути, оригинальный PDF и исполняемый checkpoint не публикуются.

## Воспроизведение расчёта

Нужен Python 3.10+, сторонние библиотеки для модели не требуются. Из этой папки:

```powershell
python calculations/forecast_model.py
python calculations/verify_forecast.py
```

Проверяются арифметика, единицы, границы и соответствие входов — **не достоверность авторских предположений**. Для нового исследования откройте корневой `AGENTS.md` репозитория и передайте агенту `task.md`, `sources.md` и бриф из кабинета конкурса; эта папка является комплектом результатов, а не возобновляемым состоянием агента.
