# Пример кластерной карты

Авторский учебный кейс catalog-evaluation, не официальный конкурсный бриф и не реальные рыночные наблюдения.

Скачайте [index.html](index.html) и откройте в браузере: карта работает автономно, без сервера и внешних ресурсов. GitHub показывает исходный HTML; размещение сайта для этой демонстрации не настраивалось.

В карте: 3 источника, 6 оснований, 4 варианта, сохранённые зависимости, блокер аудита и следующий шаг. Рекомендация агента отделена от выбора человека; эксперимент только запланирован. Пунктир означает навигационную группировку.
