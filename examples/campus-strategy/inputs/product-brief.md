# Предоставленный проект: «Зачёт»
Источник: собственные материалы команды, README и server.py исходной версии ce8ce45.
Дата разбора: 14 ноября 2026. Это рамка учебного кейса, не исследование спроса.

Запрос владельца: «У нас есть кабинет студента. Что доделать в первую очередь,
чтобы он помогал решать учебные вопросы, а не был ещё одной витриной?»

Исходная версия содержит вход, два вымышленных профиля, расписание, оценки,
подачу заявки, уведомления и справочного помощника. Заявка сохраняется со
статусом «Принята». В исходной версии нет операции сотрудника для завершения
обработки и нет выдачи результата. Публичный адрес в README не указан.

Рамка для сравнения: ограниченный конкурсный прототип, только вымышленные
данные, без интеграции с вузом, без официальной электронной подписи.
Главный получатель — команда продукта. Цель — выбрать следующий законченный
сценарий для демонстрации и план реальной проверки его полезности.
Готовность к пилоту не означает готовность к промышленной эксплуатации.
