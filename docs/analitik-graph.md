# Подключение Analitik Graph

Новый агентный репозиторий может читать аналитические результаты из локального экземпляра Analitik Graph. Это опционально: демо-кейс и расчёты в `scripts/` работают сами по себе.

## Что уже можно брать из Analitik Graph

- список баз, роль таблиц и общий ключ рабочего пространства;
- граф рабочего пространства/атлас с межтабличными связями;
- overview конкретного датасета;
- путь клиента с целью и фильтром сегмента.

В описании выводов сохраняйте, что атлас и пути отображают наблюдательные связи, используйте термины «связано/ассоциировано» до причинной проверки.

## Read-only адаптер

Клиент `tools/analitik_graph.py` разрешает только `127.0.0.1` или другой literal loopback IP. Он не отправляет данные за пределы компьютера и не вызывает API чата, конфигурации, записи/удаления датасета, SQL, append или refresh.

```bash
python3 tools/analitik_graph.py workspace
python3 tools/analitik_graph.py atlas
python3 tools/analitik_graph.py overview <dataset-id>
python3 tools/analitik_graph.py journey --body-file path/to/journey-request.json
```

Пример запроса для пути:

```json
{
  "dataset": "<events-dataset-id>",
  "goal": "Оплата",
  "segmentColumn": "Устройство",
  "segmentValue": "Android"
}
```

Можно переопределить адрес только локального экземпляра через `ANALITIK_GRAPH_URL=http://127.0.0.1:8080`. Адаптер требует уже запущенный Analitik Graph. Он является тонким HTTP-клиентом, не проксирует API-ключи и не подключается к удалённой базе.

## Ограничения

Текущий MVP не передаёт файлы новой системы в Analitik Graph, не запускает LLM-панель Analitik Graph и не пишет результаты обратно в её workspace. Результаты копируются в Evidence Ledger с указанием API-пути/датасета/параметров. Перед использованием настоящих корпоративных материалов требуется явное разрешение владельца данных и review безопасности.
