# Проверяемая исследовательская развилка

Полностью авторский вымышленный пример, не официальный бриф и не ресурсы команды.
Исходное состояние: W1 неизвестно, DEV условно доступен на 10 чел·ч. Разрешение
на прототип не закрывает оценку работ. Результат развилки UNKNOWN: требуется
целевая оценка, бумажный вариант не назначается автоматически.

```text
python scripts/start.py examples/research-branches-case/project.json --json
python scripts/research_selection.py report examples/research-branches-case/project.json
python scripts/verify_branch_demo.py
```

Последняя команда работает в временной копии. Новое авторское условие с оценкой
W1=6 и W2=2 чел·ч при ёмкости 10 даёт условную ветку PROTOTYPE. Затем тот же
объём при ёмкости 4 даёт PAPER, поскольку O2 отдельно проверен: 2 чел·ч при
ёмкости 3 и достаточные компетенции/календарный план. Суммы часов не сравниваются
с календарными днями. Искусственное окно 2099 года — условие устойчивого теста,
не срок конкурса и не реальное обещание доступности команды.

Сначала фиксируется изменение источника и stale старого разбора, затем явно
пересматриваются основания и ресурсный план, после — развилка исследования.
Старые версии, источники и checkpoint-история сохраняются. Скрипт демонстрации
явно меняет состояние как автор сценария; сам resolver ничего не записывает.
Рекомендованный O1 и отсутствие выбора человека сохраняются: PAPER — предложение
для владельца, не запись его решения. При конфликте с выбранной ставкой ready
остаётся false. Это тест механизма, не реальный эксперимент или LLM benchmark.
