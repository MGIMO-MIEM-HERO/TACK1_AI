# Авторский пример проверки осуществимости

Это вымышленный тест, не официальный бриф конкурса и не ресурсы нашей команды.
Искусственное окно 2099 года используется для устойчивого календарного теста;
это не срок конкурса и не прогноз. Никто реально не соглашался и не выполнял
работы. Источники описывают три независимых условных ресурсных сценария.

В исходном состоянии сохранён достаточный сценарий: оценка O1 — 6+2 чел·ч,
вымышленная ёмкость DEV — 10 чел·ч, календарная последовательность оценочная.
Бумажный O2 отдельно требует 2 чел·ч при ёмкости ANALYST 3 чел·ч. Выбора человека нет.

```text
python scripts/start.py examples/feasibility-case/project.json --json
python scripts/feasibility.py report examples/feasibility-case/project.json
python scripts/verify_feasibility_demo.py
```

Последняя команда работает в временных копиях. Достаточный сценарий даёт
feasible с сохранёнными допущениями. Неизвестная оценка W1 даёт unknown и целевое
уточнение, а не автоматическую рекомендацию бумаги. В дефицитном условии 8 чел·ч
плана против 4 чел·ч ёмкости делают O1 infeasible в данном распределении; O2
остаётся отдельно проверенной альтернативой. Владелец должен сам решить,
менять ли вариант или план. При конфликте итоговый экспорт блокируется.
