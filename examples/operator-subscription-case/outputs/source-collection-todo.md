# Источники, которые нужно собрать до финальной версии

Сессия подготовки работала с ограниченной сетью: прямой доступ к сайтам был закрыт прокси, и все источники известны только по поисковой выдаче (`verification: search_snippet`). Валидатор не позволит пометить такие доказательства как `corroborated`. Порядок работы для каждого источника:

```bash
# если сеть открыта
python3 scripts/snapshot.py examples/operator-subscription-case/project.json --source-id <ID> --url <URL> \
    --excerpt "<точная цитата>" --published-at <дата>
# если страница открыта инструментом IDE (WebFetch/браузер), а прямой HTTP закрыт
pbpaste | python3 scripts/snapshot.py ... --stdin --via agent_tool_snapshot --excerpt "..."
# затем
python3 scripts/checkpoint.py examples/operator-subscription-case/project.json resume   # что пересмотреть
```
