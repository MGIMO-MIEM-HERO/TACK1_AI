# Паспорт решения — авторский демонстрационный кейс

Все ресурсы, сроки, данные и ответы владельца здесь вымышлены. Это не реальные
согласования участников команды, не официальный бриф и не результат LLM benchmark.

Исходная рекомендация O1 — условный локальный прототип. Разрешение, подтверждение
исходных данных и согласование рекомендации записаны раздельно. Затем новый файл
меняет условие: на оценочный объём 8 чел·ч доступно 4. Отдельно проверенная бумажная
подготовка требует 2 чел·ч при ёмкости 3. После пересмотра ресурсного плана и
исследовательской развилки PAPER агент предлагает O2; прежние ответы становятся
историческими. Новый вымышленный ответ относится только к рекомендации O2.
Разрешение на действия с O2 отдельно не записано. Выбор в chosen_option_id и
обязательства не назначаются автоматически. Окно 2099 года — условие устойчивого
теста, не срок конкурса или обещание доступности людей.

[Снимок паспорта](passport.md) доступен для чтения. Актуальная карточка строится
из [состояния проекта](project.json), исходных файлов и истории контрольных точек:

```text
python scripts/start.py examples/decision-passport-case/project.json --passport
python scripts/decision_passport.py examples/decision-passport-case/project.json --json
python scripts/verify_passport_demo.py
```

Последняя команда воспроизводит весь путь в отдельной временной копии исходного
research-branches-case и проверяет старые/новые версии, ответы и отсутствие записи
при повторном открытии. Этот пример создан из его авторских материалов с отдельным
project_id. Исходный пример не изменён.
