# Обещание «сократить время подготовки вдвое»

Авторское вымышленное условие, не официальный бриф конкурса. Помощник только
планируется; измерений времени нет. Отсутствие измерений не доказывает ложность.

- [Отдельный аудит обещания](claims-audit-R1.md).
- [Записка с аудитом](decision-brief.md).
- `review.json` — заполненная версия, записанная CLI в `project.json`.

Цепочка: M1 → планируемая C1 → E1/BRIEF как контекст отсутствия измерений →
«Планируем помощника для составления плана подготовки. Влияние на время ещё
не измерено». Новый текст — предложение агента, не выбор владельца.

```sh
python scripts/project_tool.py audit examples/marketing-claims-case/project.json --ready --quality
python scripts/verify_claims_demo.py
```

Последняя команда использует временную копию: возвращает исходное обещание
в сообщение, проверяет stale и запрет финального экспорта, затем явно применяет
подготовленный безопасный текст и сохраняет новую версию. Реальный эффект,
вероятность успеха, длительность и стоимость не выдумываются.
