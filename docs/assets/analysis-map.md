# Основания карты анализа

[SVG-карта](agent-analysis-map.svg) показывает сохранённое обоснование
рекомендации на **вымышленном учебном снимке**
[paired-case-review](../../examples/paired-case-review/README.md).
Это не реальные данные, текущая ресурсная оценка или запись скрытых рассуждений
модели. Подписи — краткий редакторский пересказ сохранённых записей.

## Что связано на карте

| Узел / связь | Сохранённое основание |
|---|---|
| Вопрос решения | `research_questions.Q1`: какие ограничения исключают варианты подготовки |
| POLICY v2 → E9 | `evidence.E9.support`: нет разработчика до срока, замены и готового прототипа; [условие, строка 2](../../examples/paired-case-review/inputs/policy.md) |
| E9 → устаревшие E4/H2 | E4 и H2 имеют `status: stale`; старое условие о доступном разработчике отозвано |
| POLICY v2 → E10 | `evidence.E10.support`: бумажный план допустим без кода; [условие, строка 4](../../examples/paired-case-review/inputs/policy.md) |
| E11: две разные причины | Задержка интеграции сама по себе не запрещала локальную демонстрацию; недоступность разработчика — отдельная причина |
| Гипотеза H1 | Модельное предпочтение из NOTES не подтверждает спрос. Пунктир от E10 означает, что разрешённый бумажный шаг тоже не доказывает эффект, а не происхождение H1 из POLICY |
| Неизвестное | `unresolved_questions`: часы команды, материалы, спрос и эффект не подтверждены. E7 фиксирует отсутствие реальных измерений обещанного эффекта |
| Сравнение O0–O3 | `options`: выгоды, затраты, риски и возражения; `recommendation_rationale`: O0 при нехватке ресурса даже на бумагу, O3 при недостаточной ценности обучения |
| Предложение O2 ≠ выбор O1 | `recommended_option_id: O2`, `chosen_option_id: O1`; прежний выбор не заменён автоматически |
| Повторное сравнение | Смена ресурсных предпосылок требует пересмотра; наличие ресурса не означает автоматического выбора O1 |

Все поля находятся в [project.json](../../examples/paired-case-review/project.json).
Факты E9/E10/E11 — о содержании авторского условия, не независимые наблюдения
готовности продукта. Вариант O2 не проверяет реализацию, реальный UX или спрос;
разрешение подготовить бумагу не подтверждает часы и комплектность материалов.
На карте нет численных весов, вероятностей или выдуманного согласия владельца.

## Исходник и воспроизведение

[Генератор](../../scripts/build_agent_analysis_map.py) работает на Python stdlib,
читает только публичный учебный JSON и ничего не записывает в кейс. Перед
построением сверяет используемые ID, тип гипотезы, статусы и два разных выбора.
Содержательные краткие подписи редактируются в исходнике и проверяются по кейсу.

```sh
python scripts/build_agent_analysis_map.py
python scripts/build_agent_analysis_map.py --check
```

SVG содержит только текст и фигуры с системными шрифтами, без JavaScript,
внешних ресурсов и пользовательских материалов. В README он отображается
обычной Markdown-картинкой. Проверены XML, ссылки и отрисовка в 900/390 px:
картинка загружается, текст остаётся внутри карточек, горизонтальной прокрутки
нет. Изображение на мобильном экране занимает около 343 px.
