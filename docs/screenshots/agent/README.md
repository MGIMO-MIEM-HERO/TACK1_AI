# Снимки встроенной визуализации

В README размещены пять отдельных изображений с пояснениями, по образцу
разделов со скриншотами в README сайта «Кампус». Это снимки настоящего
`templates/work-graph.html`, а не нарисованные схемы или реконструкция мыслей.

| Файл | Действие в карте | Что видно |
|---|---|---|
| `01-overview.png` | Свернуть группы, раскрыть «Источники», вместить группу | Авторские документы, модельные материалы и синтетические таблицы |
| `02-evidence.png` | «Путь решения» → O2 → «Фрагменты, отношения и ограничения» | Отрывок POLICY → E9, место проверки и записанное объяснение связи |
| `03-status.png` | «Состояние проекта» → «Вопросы без ответа» | Блокеры, запрос владельцу, открытые вопросы и следующий шаг |
| `04-scenarios.png` | «Что, если…» → S-CASE-REVIEW → SC1 | Все альтернативы в условном сценарии отсутствия исполнителя для бумаги |
| `05-history.png` | «История решения» → checkpoint:2 | Сохранённая заметка о пересмотре; рекомендация O2 отдельно от выбора O1 |

Каждому изображению соответствует узкий вариант `*-mobile.png`. README
использует `picture` с выбором источника до 600 px и обычным `img` по умолчанию.
[GitHub поддерживает элемент picture](https://docs.github.com/ru/get-started/writing-on-github/getting-started-with-writing-and-formatting-on-github/quickstart-for-writing-on-github).
PNG показываются без JavaScript, сервера и установки библиотек.

## Данные и границы

Источник — [вымышленный учебный paired-case-review](../../../examples/paired-case-review/README.md).
Снимки показывают сохранённые основания, объяснения и оценки. Они не раскрывают
скрытые рассуждения модели, не доказывают спрос и не являются независимой
проверкой истинности. Разрешение действовать не подтверждает ресурс;
гипотеза и неизвестное не становятся фактом. Сценарий не применяется к выбору.

Это фрагменты интерфейса: внутренние полосы прокрутки остаются видимыми.
Обрезка ограничена выбранным экраном или карточкой, содержимое не переписано.
Подписи к картинкам находятся в Markdown. Исходный кейс не изменяется.

## Воспроизведение

```sh
python scripts/capture_readme_screenshots.py
```

Для получения новых снимков нужны Edge и Python-пакет `websocket-client`,
как для существующих браузерных проверок. Читателю README они не требуются.
Скрипт создаёт локальный HTML в `projects/readme-screenshots/`, открывает его
в отдельном профиле Edge с выделенным портом, выбирает реальные режимы карты
и сохраняет PNG через браузер. Текст и стили интерфейса не подменяются.
Технический ID одной карточки добавляется только для выбора области снимка.

`capture.json` содержит ID кейса, SHA-256 исходного JSON, нормализованный текстовый хеш, размеры областей и
подтверждение неизменности кейса. Каждый кадр также проверяет неизменность
данных графа. Время в кадрах — часы фактического экспорта; оно меняется при
повторной съёмке и не является датой принятия решения.

Проверено: все десять PNG открываются; README при 900 px выбирает пять широких
изображений, при 390 px — пять мобильных; нет горизонтальной прокрутки.
Ссылки и `git diff --check` проверены. Это проверка отображения документации,
не полный аудит доступности или качества решений агента.
