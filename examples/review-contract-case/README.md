# Пример контракта содержательной проверки
Авторский учебный кейс, не официальный бриф и не проведённое исследование.
Нужен только документ. Аудит проверяет явные основания, 24 плановые попытки
(12 сценариев × 2 варианта), предложенный порог и актуальность самопроверки.
`review_record_complete` не означает независимую истинность или проверенный спрос.

Запуск: `python scripts/start.py examples/review-contract-case/project.json --json`.
Строгая проверка: `python scripts/project_tool.py audit examples/review-contract-case/project.json --ready --quality`.
