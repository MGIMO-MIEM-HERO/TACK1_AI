# Карточка модельного респондента (СИНТЕТИКА)

> Модельный респондент — не человек. Его ответы — гипотезы, `claim_type: hypothesis`, источник
> `kind: model_respondent`. Никогда не цитируйте его как «пользователи говорят».

| Поле | Значение |
|---|---|
| ID персоны | P-… |
| На чём основана | ID открытых фактов (E-…) + явные допущения |
| Допущения | что выдумано для роли (возраст, ситуация, мотивы) |
| Ситуация выбора | когда и почему сталкивается с продуктом |
| Текущие альтернативы | чем пользуется сейчас |
| Известные ограничения | бюджет, навыки, доверие |
| Чего персона НЕ знает | условия продукта, которых нет в открытых источниках |
| Роль в наборе | типичный / крайний / скептик / не-пользователь (в наборе обязателен скептик или не-пользователь) |

## Протокол генерации

1. Набор: 3–5 персон, минимум одна скептическая и одна «не замечает продукт».
2. Вопросы — из реального гайда (`templates/interview-guide.md`): о прошлом эпизоде, альтернативах, отказе.
3. Каждой персоне задать вопрос «что заставит вас отказаться/не заметить».
4. Сохранить: модель, дату, текст вопросов, карточки — в `interviews/synthetic/<дата>-*.md` с баннером «СИНТЕТИКА».
5. Из ответов выписать гипотезы H-SR-… с критерием опровержения в реальном исследовании.
6. Записать действие в журнал: `python3 scripts/ledger.py log … --step research --action "модельные респонденты" --model …`.
